# UCAS 报告写作与版式

## 资料优先级

本次老师要求和记录表 > 对应版本实验指导书 > 课程空白模板 > 同学/往届报告。
记录表也可能给出处理公式，核对其单位；报告中的数值计算、仪器参数和旧日期不直接继承。
旧参考中的范围、公式与本次指导书不同，应写清采用哪种测法。
随附来源清单是查找入口，不等于已逐份验证内容。

## 内容

按实际任务组织，通常包括：实验目的；仪器及已知规格；原理与适用条件；
实际实验内容；原始电子表格；计算、拟合与图表；误差/问题讨论；实际思考题；总结；原始记录和预习附录。
可把过程、数据、分析按子实验合并叙述。不要机械复制旧生成器的固定七节结构。
仪器参数、背景噪声、采样电阻、波长、分辨率、温度等没有依据时标为待补，而非取旧报告的数值。

正文必须重排清晰的电子表格，照片放附录。这是已读取的光电探测2025报告要求，也与现有报告常用结构一致。
该光电探测要求还规定原理不超过两页；不能将此篇幅限制自动推广到其他实验。
原理说明量的含义、单位、成立条件和必要光路/电路示意；照片没有记录的操作不能写成亲历事实。

结论需连接实测数值与具体问题。误差讨论区分：
- 已量化的不确定度；
- 由数据支持的趋势/残差；
- 可能的系统误差，明确其方向与证据边界。
不用“非常吻合”“误差很小”等空话掩盖异常。
没有实际思考题时不编造任务；可保留与结果相关的讨论。

## 计算与图表

- 中间计算保留精度，最终按仪器读数、拟合精度或不确定度统一舍入。
- 不确定度通常保留1~2位有效数字，中心值舍入至对应小数位；说明标准或扩展不确定度及覆盖因子。
- 仪器分辨率、最大允差与标准不确定度不同；缺规格时不虚构 u_B。
- 误差传播考虑共享参数的相关性；逐差数据若重叠不能默认独立。
- 横纵轴写物理量和单位，测量点与模型曲线区分，比较多组数据用图例。
- 不用高阶多项式仅为“穿过每个点”。拟合范围、模型与排除点需有理由。
- 定性光学/虚拟仪器实验保留真实现象图、前面板/框图；不能用生成图片冒充实测照片。
- 原始表、处理表、图通过显式 id 连接，不按文件排序猜关系。

## 模板与交付

assets/report.tex 是基于课程常用表头重新整理的轻量模板，保留原课程 LaTeX 模板作者说明。
采用 Fandol 字体与常见宏包，减少系统字体依赖；模板不是新的学校官方认证版本。
正文结构由 Codex 写在 content.tex，生成的图表/数值片段自动插入。
个人信息留白或“待补充”时输出属于草稿。预习照片、教师签字等只能采用用户提供的真实材料。
若用户仅提供记录表，先产出其余完整内容，最后一句列出缺少的预习附件，不反复要求用户确认流程。

交付工程包含 data.json、inputs.json、analyze.py、physics.py、reportlib.py、results.json、
content.tex、report.tex、generated/、figures/、photos/ 和 report.pdf。
工程中的 .build/、.review/ 属检查记录；项目公开发布包不包含真实学生工程。
