# 12 虚拟仪器

## 范围与来源
来源：《12.实验指导书-.虚拟仪器(请使用此版本).pdf》25页。
不同年份实验编号不一致，按项目名称和用户截图识别：
模拟/实测温度、输出采集、伏安特性等，不照旧报告的“实验2/3/4”机械对齐。

## 输入
记录LabVIEW前面板、程序框图、仪器连线图/电路、量程与采样设置；
I-U 数据可能在照片，也可能是Excel/CSV，存在原电子数据时优先使用并记录文件来源。
当前 init 的直接输入为照片；电子表格由 Codex读取后额外保存原件和来源清单，
涉及电子原表而没有对应照片时须扩展项目来源记录，不能假称来源于不存在的照片。
本版本 data schema 原始行要求照片来源；纯电子表格任务应明确此限制，不伪造 image 字段。

## 伏安法
先确认I、U测量位置，电流可能由采样电阻上的电压推得。
若拟合U对I，斜率为R；拟合I对U，R=1/斜率，单位转换要一致。
截距可能反映偏置，不能自动强制通过原点；用残差判断测量/模型。
二极管正反向分开画图，电流单位量级通常不同，零或负电流不能直接取log。
只有适用范围和温度信息充分时做二极管参数拟合；不能把电源电压直接当管压降。
量程、分辨率、采样率从界面或记录读取，不从参考作者环境继承。

## 程序与过程描述
根据真实框图解释数据流、循环/时序、输入输出；
若只有前面板，不能声称核查了程序逻辑。
.VI 文件不是可由文本猜出的源代码；有截图用截图，无截图不臆造框图。
模拟信号要标明模拟，与实际采集电压/温度分开。
本次记录没有运行证据时，不能写“程序运行正常且与实测一致”。

## 输出
真实程序/界面图，测量电路说明，原始与处理表，电阻斜率拟合/二极管曲线，
数据流或时序相关实际思考题，区分软件实现与实验测量误差。
