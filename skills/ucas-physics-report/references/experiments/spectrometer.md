# 08 分光仪器

## 范围与来源
来源：《分光仪器（适用于4-6周）》9页；三棱镜顶角/最小偏向角、
光栅波长测量和数字光谱仪按照片实际项目选择。
参考图不能替代本次光谱照片或刻度读数。

## 角度处理
原始数据保留度、分、秒以及游标编号，转为度后再做环形差值。
跨0°用最短有向角差，不能直接算 359°-1°=358°。
两游标约相差180°；合并前先统一同一方向/参考系，不能直接算其算术平均。
先明确记录是望远镜方位、左右对称读数、两反射面读数，还是已处理的角。

## 三棱镜
反射法两面反射方向夹角常为2A，先核对选取的内/外角，再取A。
最小偏向角 delta_min 由直射光与最小偏向方向的差得到，双游标结果交叉核对。
n=sin((A+delta_min)/2)/sin(A/2)，计算函数必须转弧度。
多条谱线得到 n(lambda)，没有足够谱线不强做色散高阶拟合。
误差传播使用角的弧度标准不确定度，保留 A 与 delta 共享读数的相关性影响。

## 光栅
正入射时 d*sin(theta)=m*lambda。
左右同级衍射谱线夹角的一半给 theta，须明确零级和级次正负。
d 从线密度转换：如 line/mm，先得mm再转m；不能把线密度数值当间距。
已知 lambda 求 d 或已知 d 求 lambda 二选一标清本次目的，不循环“校准后验证”当独立结果。
不同级次/双游标可分别计算后比较，异常谱线应核对认线而不是自动换波长。

## 图表与问题
输出原始角度表、规范化角差、折射率/波长处理表；
只有光谱/色散数据充分时画相应图，不硬造“一表一图”。
讨论自准直、望远镜/平行光管调节、游标偏心消除和最小偏向判据。
