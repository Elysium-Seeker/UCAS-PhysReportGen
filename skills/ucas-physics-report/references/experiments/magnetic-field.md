# 03 磁场测量

## 范围与来源
来源：《磁场的测量（适用于4-7周）》PDF（17页），本次霍尔探头/线圈记录。
先判断是直流霍尔法、交流磁场、圆线圈轴向分布还是亥姆霍兹线圈。
当前目录主要参考报告为 Word；用文档读取工具读正文，不能因没有 tex 就跳过。

## 必需输入
探头灵敏度及单位、工作电流、励磁电流、线圈半径/匝数/间距、轴向零点；
每组极性组合的带符号电压；位置和角度；背景/零点读数。
区分传感器标定系数“电压/磁场”与材料霍尔灵敏度“电压/(电流*磁场)”。

## 分析
霍尔关系 U_H=K_H*I_work*B。
若用四次换向法，先列出每次工作电流和磁场的符号：
只提取同时对两种换向均为奇的分量，U_H=sum(s_I*s_B*U_measure)/4。
读数记录规则可能为幅值或带符号值，先核对，不能机械套符号。
根据真正使用的灵敏度定义计算 B；mV、mA、mT 转换逐一列出。

圆线圈轴向场：
B(z)=mu0*N*I*R²/[2*(R²+z²)^(3/2)]。
两相同线圈中心位于 +/-a/2 时叠加两项；a=R 才是标准亥姆霍兹条件。
画 B-z 的实测/理论同图，按实测坐标零点对齐，保留背景修正的依据。
如果是 B-I 或 B-angle 数据，分别检查线性关系或投影余弦关系。
不把探头未处于线圈轴线上产生的偏差自动当成公式失效。

误差讨论包括霍尔片方向、零点、工作电流稳定性、线圈几何与地磁背景。
